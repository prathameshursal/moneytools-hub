Percentage mistakes that cost money

  • Successive discounts do not add. 20% off then 30% off is 1 − 0.8 × 0.7 = 44% off, not 50%.
  • Percentage points are not percentages. If a rate rises from 5% to 7%, it rose by 2 percentage points, which is a 40% increase.
  • Reverse percentages trip people up. A price that rose 25% and then fell 25% is still 6.25% below the start, because the second percentage applies to a different base.
  • GST extraction is division, not subtraction. Removing 18% GST from ₹1,180 leaves ₹1,000, not ₹967.60, because the tax was 18% of the base (₹1,000), not of the total.

Frequently asked questions

How do I calculate a tip or GST mentally?

Move the decimal point one place for 10%, halve it for 5%, and add. For 18%, take 10% + 5% + 3 × 1%.

Can I enter negative numbers?

Yes, in the change mode. A negative old value flips the direction logic, which the tool handles using the absolute base.

Why is percentage change from 0 undefined?

There is no meaningful base to measure from. A rise from 0 to any value is infinite in percentage terms.

Does this work on mobile?

Yes, the whole site is designed mobile-first and this page uses numeric keypads on phones.
